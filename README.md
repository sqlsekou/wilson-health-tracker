# Wilson County Health Inspection Tracker

A searchable, mapped view of restaurant, pool, and facility health inspections in Wilson County, Tennessee. It turns the weekly "Health Scores: Wilson County" posts from [Wilson County Source](https://wilsoncountysource.com) into one running dataset with a dashboard on top.

Created by [Royal Blue Analytics](https://royalblueanalytics.com). This is an independent demo and is not affiliated with Wilson County Source or the Tennessee Department of Health.

## What is in here

| Path | Purpose |
|---|---|
| `index.html` | The dashboard. Static HTML, CSS, and vanilla JS with Leaflet for the map. No build step. |
| `data/inspections.json` | Dashboard data, generated by `scripts/build.py`. |
| `data/inspections.csv` | Same rows plus `source_url`, `geo_source`, and `geo_precision` for Excel, Power BI, or Tableau. |
| `data/geocode_cache.csv` | Every address that has been geocoded, with its coordinates. Never regenerate from scratch. |
| `data/posts_seen.json` | Source posts already processed, so weekly runs only touch new ones. |
| `scripts/scrape.py` | Finds roundup posts through the WordPress REST API and parses their tables. |
| `scripts/geocode.py` | Census batch geocoder first, OpenStreetMap Nominatim as a fallback. |
| `scripts/build.py` | Joins coordinates onto the rows and writes the JSON and CSV. |
| `.github/workflows/refresh.yml` | Weekly refresh that commits new data and redeploys the page. |

## Data

Underlying data is Tennessee Department of Health inspection results, as published by Wilson County Source. Each record is one inspection:

```
[name, score, result_text, street, city, zip, facility_type, inspection_type, date, lat, lon]
```

- `score` is 0 to 100, or `null` when the published result is not a number.
- `result_text` holds non-numeric results such as "Approval" for child care facilities.
- `inspection_type` is Routine, Follow-Up, Complaint, or blank when the source table did not include it.
- `lat` and `lon` come from the US Census geocoder or OpenStreetMap. Unmatched addresses stay `null`. Nothing is estimated.

The scraper handles the three table layouts the site has used since January 2024. A few July 2024 posts were published without addresses; those rows are kept with a blank address so the score history is complete.

Roundup posts titled "Lowest Food Health Scores" and "Perfect Health Scores" are read as a secondary source and deduplicated against the weekly tables on name, street, date, and inspection type.

## Run it locally

```bash
pip install -r requirements.txt
python scripts/scrape.py      # new posts only; add --all to re-parse everything from the cache
python scripts/geocode.py     # only looks up addresses not already in the cache
python scripts/build.py
python -m http.server 8000    # then open http://localhost:8000
```

The scraper identifies itself with a clear User-Agent, waits between requests, and backs off when the site asks it to. Fetched post HTML is cached under `cache/` (ignored by git).

## Embed it

```html
<iframe id="wchs" src="https://YOUR-HOSTED-URL/" width="100%" height="800"
  style="border:0;" loading="lazy" title="Wilson County Health Inspection Tracker"></iframe>
<script>
window.addEventListener('message', function (e) {
  if (e.data && e.data.type === 'wchs-height') {
    document.getElementById('wchs').style.height = e.data.height + 'px';
  }
});
</script>
```
